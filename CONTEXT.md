# Agentic Afker

A desktop companion idle game set during the AI boom. The player trains a dumb Agent into a useful one by levelling Skills over time. Melvor Idle-style gathering/production balance with an AI-agent theme. Primary interaction is a desktop overlay; tray minimisation and a Game Window for skill management.

## Language

**Agent**:
The in-game character the player trains from incompetent to useful. The visible companion in the overlay. Transforms at Form Stage thresholds; individual Skills add cosmetic Equipment.
_Avoid_: Pet, avatar, bot, AI (in the LLM sense)

**Skill**:
A trainable capability the Agent develops over time. Each Skill decorates the Agent with Equipment that improves as the Skill levels. Skills are either Gathering or Production, and belong to a Domain.
_Avoid_: Stat, ability, profession

**Domain**:
A thematic branch of Skills representing a different aspect of AI (e.g. Data Pipeline, Prompt Economy, Office Assistant, Content Creator). Alpha ships one self-contained Domain; Beta+ introduces cross-Domain inputs. Each Domain has its own gathering → production chain.
_Avoid_: Tree, branch, category

**Orchestration**:
The hub Skill that consumes outputs from multiple Domains. Unlocks mid-game and scales through endgame. The capstone that makes the Agent truly useful.
_Avoid_: Meta skill, automation, management

**Gathering Skill**:
A Skill that produces raw inputs (e.g. scraping data, collecting prompts). Feeds Production Skills.
_Avoid_: Resource skill, harvesting

**Production Skill**:
A Skill that consumes gathered inputs to produce outputs (e.g. fine-tuning, generating reports).
_Avoid_: Crafting skill, processing

**Equipment**:
Cosmetic items tied to a Skill that upgrade at level milestones within that Skill.
_Avoid_: Gear, loot, item

**Form Stage**:
A major visual transformation of the Agent, unlocked when Total Level crosses a threshold. Tells the dumb-to-useful arc (e.g. boot-loop blob → competent assistant).
_Avoid_: Evolution, tier, rank

**Total Level**:
The sum of all Skill levels. Gates Form Stage unlocks.
_Avoid_: Combat level, overall level

**Token**:
The passive output currency generated by Production Skills. Spent on Skill Upgrades and Infrastructure.
_Avoid_: Gold, coins, credits

**Skill Upgrade**:
A Token-purchased boost tied to a specific Skill, unlocked at level milestones (10, 20, 30…). Improves that Skill's XP rate or Token yield.
_Avoid_: Perk, talent, boost

**Infrastructure**:
A Token-purchased global upgrade that buffs all Skills. Gated by Total Level thresholds (e.g. "Expanded Context Window" at Total Level 100). Includes Offline Cap upgrades.
_Avoid_: Building, facility, module

**Offline Cap**:
The maximum duration of offline progress granted when the app is relaunched after being closed. Starts at 8 hours; upgradeable with Tokens up to 3 days.
_Avoid_: Offline limit, away time

**Save**:
The player's persistent game state stored locally. Exportable/importable manually; Steam Cloud sync is a future goal.
_Avoid_: Profile, account

**Overlay**:
The Agent window — a small, always-on-top surface (roughly 300×200px minimum) showing the Agent and its current activity. Click-through by default; a hotkey toggles Interact Mode to enable clicks. Shows Milestone popups passively; a minimal progress HUD is added post-Alpha.
_Avoid_: Widget, pet window, companion window

**Milestone**:
A notable progression event (level up, Form Stage unlock, Skill Upgrade available) surfaced as a brief visual popup on the Overlay.
_Avoid_: Achievement, notification, alert

**Interact Mode**:
When enabled, the Overlay captures mouse clicks. Reveals controls including a button to open the Game Window. Disabled by default so the Overlay doesn't block desktop work. Toggled via hotkey.
_Avoid_: Interactive mode, unlock

**Game Window**:
The full application window for skill trees, upgrades, and skill switching. Opened via a button on the Overlay (in Interact Mode) or from the tray menu. The Overlay remains visible alongside it.
_Avoid_: Main window, dashboard, panel

**Tray**:
The minimised state where the app lives in the system tray with no visible overlay or game window.
_Avoid_: Background mode, minimised

## Release phases

**Alpha**:
Vertical slice. One Domain (Data Pipeline): Scraping → Labelling → Fine-Tuning. 2 Form Stages. Placeholder art. Proves overlay + idle loop + Token economy.

**Beta**:
Melvor chapter. 8–10 Skills across 2–3 Domains with cross-Domain inputs. Orchestration unlocks mid-game. 3–4 Form Stages. AI-generated pixel art with style guide.

**1.0.0**:
Full game. 15+ Skills across all Domains. Orchestration scales to endgame. All Form Stages. AI-generated base art with human cleanup if Beta quality holds.

## Example dialogue

> **Dev:** When the player switches from Woodcutting to Mining, where does that happen?
>
> **Expert:** We don't have Woodcutting — Alpha is the Data Pipeline Domain: Scraping feeds Labelling feeds Fine-Tuning. Beta adds Domains like Prompt Economy and Office Assistant. You switch active Skills in the Game Window.
>
> **Dev:** What's the player actually grinding toward?
>
> **Expert:** Two tracks — Skill XP unlocks production chains and Form Stages. Production Skills passively generate Tokens; you spend them on Skill Upgrades at level milestones and Infrastructure at Total Level thresholds.
>
> **Dev:** And if they minimise to tray?
>
> **Expert:** Progression keeps ticking in Tray. Interact hotkey unlocks the Overlay for clicks — there's a button to open the Game Window. The Agent stays visible in its own window while you manage Skills. Close the app and you get offline catch-up up to your Offline Cap.
